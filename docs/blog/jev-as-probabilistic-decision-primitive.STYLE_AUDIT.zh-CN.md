**L1-4 工具名。** 被点名的具体对象有 Jev、TypeSafe、`jev-1.13.0`、`jev-latest`、

## L2 明细

**L2-1 开头。** 从一件具体的事切入 —— Jev 不返回散文，只返回带类型的概率答案 —— 而不是从
"随着大模型的发展"。第一句"事情是这样的"后接的是一个短促的陈述，"它压根不想跟我聊天"，
制造"然后呢"的拉力。没有教科书式开头。

**L2-2 节奏。**

- 一句话独立成段：38 处（`54 次。` / `漂亮。` / `不是。` ×5 / `第一个故事没了。` /
  `到底是谁动的？` / `12 次。一条都不许多。` / `实验没坏。` / `分析器坏了。` / `为什么？` /
  `是删故事的能力。` 等），远超规则要求的 3 次。
- 扣主线句：9 处（`好，回到实验。` / `这一段的重点是` / `这几段连起来看` / `回到开头。` /
  `后来我才发现` / `写到这里` / `顺便说一句` / `顺带一提` / `还有一件我做得挺狠的事`）。
- 疑问句刹车：6 处（`那 Agent 会不会真的好写一点？` / `到底是谁动的？` / `是不是 instructions
  更重要？` / `为什么？` ×2 / `到底要不要因为 sunk cost 把它跑掉？`）。
- 小标题：正文 0 个。这条恰好是《SKILL.md》与工作令 §4 意见一致的地方，两边都要求不用
  `##`/`###`，全文只有一级标题。

**L2-3 口语化。**

口语化表达 35 个不同条目（规则要求 8–10 个），逐条在文中计数后列出：`事情是这样的`、
`压根`、`完了`、`特别朴素`、`稍微绕`、`差点搞混`、`挺直白`、`没人会去查`、`最要命`、
`顺便说` ×2、`有点东西`、`漂亮` ×2、`吃掉` ×2、`摆在这`、`停一下`、`挺有意思` ×2、
`稳如泰山`、`底下的水一直在晃`、`挺尴尬`、`挺狠`、`顺带一提`、`顺手`、`挖好一个坑`、
`一个字都没多`、`锤子`、`钉子`、`签名字`、`我敢`、`反而`、`好看` ×6、`不是我不想报告`、
`混了`、`把问题看成钉子`、`说实话`。

论述中的故意打破 6 处：`不是。` 独立成段，两次打断一个正在成立的论断；`实验没坏。` 与
`分析器坏了。` 两段之间没有连接词；`12 次。一条都不许多。` 用重复加强而不是推进；
`这是一份 payload 上的数字` 在三个漂亮数字之后硬转折。

自嘲/承认不足 4 处：`这个 45 / 45 我一开始写错过`、`然后又出了一件挺尴尬的事`、
`这件事我没打算写成英雄叙事`、`我不是第一次做实验。但先给自己挖好一个坑，再自己跳进去，
这是第一次。`

**未做到的一项：情绪标点。** 规则要求 `。。。` / `？？？` / `= =` 至少出现一种，本文 0 处。
理由记在 §"Evidence-contract overrides"。按《SKILL.md》的通过标准，本层四项中三项通过即算
通过，所以 L2-3 判 ✅，但这一项的空缺被明确写出来而不是略过。

**L2-4 二次确认。** 改写过程中最容易被重新引入的就是这三类标点，因此这一项是在全部编辑完成
之后重跑的，不是在初稿上跑的。重跑结果同上：0 处。

## L3 明细

**L3-1 观点支撑。** 每个核心论断都带具体数字或具体代码位置，没有只有论断没有例证的空泛段落。
"效应很大 ≠ 原因已确定"这句是全文最像格言的一句，它前面是 K1 的 `0.05 < 0.10`，后面是两个
被明确拒绝的总结，支撑是够的。

**L3-2 知识输出。** 三种原语的介绍走的是"先花一分钟说清楚 Jev 到底是个什么东西，不然下面
看不懂"，然后一段一个，全部控制在一两句以内 —— 这是工作令 §9 明确要求的，也是《SKILL.md》
说的"聊着聊着顺手掏出来"，不是"下面我来介绍一下"。calibration 的分组作用域、cookbook 的
标签翻转、chaos test 的 jitter floor 都是随论述顺带带出的，没有一节是科普节。

**L3-3 文化升维。** 按类型取材，从具体事件连到更大的参照物，但参照物是方法论的而不是文学
的 —— 这是工作令 §29 指定的方向，也是本文唯一诚实的升华方式。"删故事的能力"连到
"一个用来检验发现的仓库收到了否定的检验结果"，`效应很大 ≠ 原因已确定` 连到
"如何在 AI 时代约束自己从模型输出里讲故事的冲动"。**没有引用任何文学作品、历史人物或哲学
概念**：一个测量仓库没有资格借用它们，硬借就是我们自己那条"不能因为手上有锤子就把问题看成
钉子"的规则的镜像违例。

**L3-4 对立面与同理心。** 每一层拆解都先把最诱人的读法完整说出来，再拆 —— `这么写出来，
听起来像模型在一个很微妙的边界上做了判断。` / `这个结果太容易写成「模型不敢执行」了。` /
`看到这里，很容易产生一个冲动。` / `I 比 C 低。是不是 instructions 更重要？`。读者如果
正是这么想的，会先看到自己的立场被准确复述，然后才看到它为什么站不住。

**L3-5 类型专项（调查实验型）。** 亲自下场的叙事感在，"所以我真去跑了。54 次。"；层层递进
的发现也在，而且是四层，每层都先给数字再拆：批处理 4.2647× → 稳定标签 → 0.61 门槛 →
路由 4/4。拆解的顺序刻意排成升番，工作令 §11 指定，所以最先给的是最漂亮的数字，最后给的
是最舍不得删的那个。

**L3-6 逐一展示。** 四个候选逐条展示、逐条拆解，每条都带自己的说明，不是一次性罗列。
五个退休实验只留两个展开（`10_state_length`、`11_language_pair`），剩下三个按工作令 §20
不逐一铺开。

## L4 明细

**L4-1 温度感。** 情绪表达全部是第一人称的过程记忆，不是知识性描述：`我当时冒出来的问题特别
朴素`、`我当时是真的觉得这条挺有意思`、`大到我看到它的第一反应，是想赶紧写点什么`、
`然后又出了一件挺尴尬的事`。**没有一处体感描写**（没有"愣住了"、没有"拍桌子"）——
工作令 §30 禁止编造身体反应，而这一篇不需要它们：一件真的发生过的事，过程本身就够。

**L4-2 独特性。** 这个角度换一个 AI 博主写不出来，因为它的独特之处不在文风上，在素材上：
一个附预注册、附带缺陷并被保留的分析器、附勘误表、附两条不可变日志的测量台。
别人可以模仿这个语气，但模仿不了"我删掉了七个自己写好的故事"这件事，因为那需要真的先写过
七个再真的删掉。

**L4-3 姿态。** 全文没有滑进"导师在教学生"：三条工程经验用的是"我手上剩下三条能迁移到别处
的东西"，不是"你应该这样做"；风险陈述用的是"这个限制是写下来的，不是含糊过去的"，不是
"大家一定要注意"。也没有滑进营销姿态 —— 结尾的 `NO_STRONG_JEV_SPECIFIC_NOVEL_FINDING_YET`
是一次去推广，不是一次推广。

**L4-4 心流。** 两处刻意减速，都是工作令指定的：`07_instruction_precision` 的转折点
（`问题来了。到底是谁动的？`），以及 P3 的 12 次上限（`12 次。一条都不许多。` 单独成段）。
两处减速之后都立刻回到主线，没有留在情绪里。审查中发现的唯一一处节奏偏快是结尾的删故事
回扣，已记在"修复优先级"里。

## Evidence-contract overrides

工作令 §3 定的优先顺序是：冻结证据 > `BLOG_CLAIM_CONTRACT` > 历史 provenance > Khazix 风格。
下面每一处都是这条顺序真正产生代价的地方，也就是风格想要的东西和证据允许的东西不一致的地方。
**每一次都是证据赢。**

**1. 风格要一个"卧槽"的结果，这篇的诚实结局是一个 null。**
《SKILL.md》的写作原型把文章推向一个回报时刻。这个项目真实的回报是 P3 的负结果，外加一行
`NO_STRONG_JEV_SPECIFIC_NOVEL_FINDING_YET`。处理方式是把文章结构改成**表观成果逐一拆解** ——
升番曲线还在往上走，但往上走的是拆解的质量，不是发现的体量。四个候选一个比一个更舍不得删，
最后一个的失败也最彻底。这是唯一一个既真实、又结构上站得住的读法，因此采用。

**2. 风格要"敢下判断"，合同禁止其中大多数。**
处理方式和上一条相同：文章确实下判断，但下的是关于**方法**的判断，而证据完全支撑它 ——
预注册、provenance、效应大不等于原因确定。关于 Jev 的判断严格限制在合同划定的范围内。

**3. L2-3 的情绪标点按规则未做。**
`。。。` / `？？？` / `= =` 这类标点在这篇里只有两种来源：伪造的情绪，或者刻意模仿的网红口癖。
工作令 §27 明确排除后者，§30 明确排除前者。用了就得二选一，所以没有用。这是 L2-3 四项里
唯一未做到的一项，代价被记在这里而不是被抹平。

**4. 人物画像法 = `NOT_APPLICABLE`。**
《SKILL.md》的 L3 有一节人物画像法，把冷数字变成有温度的人。这个项目里没有第三个人可以画像 ——
全部 state 是合成的，全部调用是作者自己发的，没有任何人出现在这些证据里。工作令 §28 禁止为了
通过检查而编造一个。**这一项判 `NOT_APPLICABLE`，不是"通过"，也不是"未通过"。**

**5. 固定尾部、署名与联系方式属于《SKILL.md》的作者，不使用。**
工作令 §2 禁止复制。文章以删故事的回扣结束，以作者自己的判断收尾，没有借用任何不属于这个
仓库的收尾元素。

**6. "删故事"是叙事装置，不是科学论断。**
这是全篇最需要盯着的一处：一个反复出现的叙事装置会自己长出论断的力量。`删掉了七个故事`
离 `否定了七项发现` 只有一次压缩的距离，而后者是假的 —— 七个候选里没有一个是"被证伪的发现"，
它们全部是**没有通过分诊的候选**。因此它在claim audit 里被单独列成 C-66 并归入 `B` 类
（任何关于新颖性的句子），而不是 `A` 类，scope 栏记录它在哪里被限定。

**7. 结尾证据附录的语气与正文不一致，这是有意的。**
《SKILL.md》要求全文一口气顺下来、不加小标题、语气统一。附录是仓库路径和 SHA-256，
不是散文，工作令 §24 单独为它开了口子。**风格上的不一致在这里是正确结果**：把一段
manifest 写成口语化叙事，才是真的在骗人。
